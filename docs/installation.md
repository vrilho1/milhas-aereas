# 🛠️ Instalação

## 1. Clonar o repositório

```bash
git clone https://github.com/vrilho1/milhas-aereas.git
cd milhas-aereas
```

## 2. Criar e ativar o ambiente virtual

```bash
python3 -m venv venv
source venv/bin/activate
```

## 3. Instalar dependências

```bash
pip install -r requirements.txt
```

*(Se ainda não tiver requirements.txt criado, instale: `pip install requests python-dotenv`)*
