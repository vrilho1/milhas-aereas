# 🎉 Bem-vindo ao Milhas Aéreas

Esta documentação explica como instalar, configurar e usar o monitor de milhas **Smiles (GOL)**.

## Visão Geral

- **Objetivo:** Rastrear oportunidades de passagens com milhas abaixo de um teto definido.
- **Notificações:** Alertas instantâneos diretamente no **Telegram** com links diretos para emissão.
- **Tecnologias:** Python 3.11+, Requests, BeautifulSoup, python-dotenv, GitHub Actions (CI).
